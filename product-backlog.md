# Product Backlog — RaktaSetu (Blood Bank Management System)

| ID | User Story | Priority | Story Points | Status |
|----|------------|----------|---------------|--------|
| US-01 | As a **donor**, I want to register with my personal and medical details so that I can become part of the donor database. | High | 5 | Done |
| US-02 | As a **donor**, I want to view my past donation history so that I can track when I am next eligible to donate. | Medium | 3 | Done |
| US-03 | As a **recipient**, I want to search for available blood by blood group and location so that I can quickly find a match. | High | 5 | Done |
| US-04 | As a **recipient**, I want to book an appointment to receive blood so that I can plan my hospital visit. | High | 8 | In Progress |
| US-05 | As an **admin**, I want to log in securely so that only authorized staff can manage inventory and requests. | High | 3 | Done |
| US-06 | As an **admin**, I want to update blood inventory levels so that stock data stays accurate in real time. | High | 5 | In Progress |
| US-07 | As an **admin**, I want to receive a low-stock alert so that I can proactively organize donation drives. | Medium | 5 | To Do |
| US-08 | As an **admin**, I want to approve or reject donor/recipient requests so that only verified users can transact. | High | 5 | To Do |
| US-09 | As a **recipient**, I want to receive a notification when my blood request is approved so that I know when to arrive. | Medium | 3 | To Do |
| US-10 | As a **hospital staff member**, I want to generate reports on donations and requests so that I can review monthly performance. | Low | 5 | To Do |

**Total Story Points:** 47

## Prioritization Notes
Stories were prioritized using the **MoSCoW technique**, with core donor/recipient/admin flows marked *Must Have* for Sprint 1, and reporting/notification features scheduled for later sprints.
