# Stakeholder Analysis — RaktaSetu (Blood Bank Management System)

| Stakeholder | Role/Interest | Influence | Key Expectations |
|-------------|----------------|-----------|--------------------|
| **Donor** | Individual willing to donate blood | Medium | Simple registration, ability to track donation history |
| **Recipient / Patient** | Person requiring blood | High | Fast, accurate search for available blood; easy appointment booking |
| **Hospital Admin/Staff** | Manages inventory and approves requests | High | Real-time stock visibility, ability to approve/reject requests quickly |
| **System Administrator** | Maintains system access and security | Medium | Secure login, controlled access to sensitive data |
| **Course Instructor (Professor Karki)** | Project sponsor/evaluator | High | Deliverables that meet CSE220 rubric: backlog, requirements, diagrams, test cases, GitHub workflow |
| **Development Team** | Saswat Raj Uprety & Krishna Jung Karki | High | Clear division of tasks, achievable sprint goals |

## Stakeholder Needs Summary
- **Primary users (Donors, Recipients)** need a simple, low-friction interface.
- **Hospital staff** need accurate, real-time inventory data to make time-critical decisions.
- **Project stakeholders (Instructor, Team)** need well-documented Agile artifacts demonstrating correct use of Scrum and version control practices.
