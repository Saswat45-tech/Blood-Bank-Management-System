# Blood Bank Management System (RaktaSetu)

## Project Overview
RaktaSetu is a simulated Agile software project for a **Blood Bank Management System**, developed as part of CSE220 – Principles of Software Engineering. The system is designed to connect blood donors, recipients, and hospital staff by streamlining donor registration, blood inventory tracking, and appointment-based blood requests.

This assignment simulates a real-world Agile project **without coding** — planning was done in Trello and documentation/version control was done in GitHub.

## Project Scope
RaktaSetu allows:
- Donors to register and manage their donation history
- Recipients/hospital staff to search for and request specific blood groups
- Admins to manage blood inventory, approve requests, and monitor stock levels
- Automatic low-stock alerts to notify staff when a blood group runs low

## Agile Process Used
The team followed a lightweight **Scrum** approach:
- A single Product Backlog was created and prioritized with the Product Owner
- Sprint 1 was planned with story points, assigned roles, and deadlines
- Progress was tracked on a Trello Kanban board (To Do / In Progress / Review / Done)
- Work was version-controlled through GitHub using feature branches and pull requests

## GitHub Workflow
- All repository history is maintained under **Saswat Raj Uprety's** GitHub account
- **Krishna Jung Karki** was added as a collaborator with write access
- Branches used: `main`, `UML-diagram`, `Test-Case`, `evidence/github`
- Work was committed on feature branches and merged into `main` via Pull Requests

## Reflections on Using Agile Tools
Using Trello for backlog and sprint management made it easy to visualize progress and divide ownership of user stories between two members. GitHub's branching model reinforced the discipline of committing incrementally and reviewing changes through pull requests before merging, which mirrors how real software teams collaborate even without writing production code in this assignment.
